# TicTacToe
Gibt für ein beliebig großes quadratisches Spielbrett Bewertungen für alle möglichen Spielzüge an. TicTacToe ist speziell für ein Brett der Größe 3. Es empfiehlt sich, zuerst ein paar Züge zu machen und dann die Bewertung machen zu lassen. Dies wurde durch Alpha-Beta-Suche implementiert.

Dies wurde im SoSe2026 im Modul Algorithmen und Datenstrukturen erstellt.
